# AI 腔模式清单

按"看到什么 → 换成什么"组织。词表用于扫描，判断标准仍在 SKILL.md：这句话删掉后，读者会不会少知道什么。

## 一、夸大意义与宣传腔

| 看到 | 换成 |
|---|---|
| 标志着 / 见证了 / 是……的体现 | 直接说发生了什么 |
| 为……奠定了基础 / 做出了贡献 | 说具体结果 |
| 在当今快速发展的……时代 | 删掉，直接进入问题 |
| 至关重要 / 核心 / 关键性 | 说后果："如果不做，会……" |
| 不可替代 / 独一无二 / 里程碑 | 给出可验证的差异 |
| 深刻改变 / 彻底重塑 | 说改了什么、改了多少 |

## 二、空转抽象（中文特有）

| 看到 | 换成 |
|---|---|
| 赋能 / 抓手 / 闭环 / 打通 | 具体动作："提供 API""加一层校验" |
| 多维度 / 全方位 / 深度绑定 | 列出维度本身 |
| 生态 / 体系化 / 规范化建设 | 说做了哪件事 |
| 进一步 / 切实 / 扎实推进 / 持续优化 | 删掉；有具体动作就写动作 |
| 高质量发展 / 提质增效 | 写指标 |

## 三、评价性包装

| 看到 | 换成 |
|---|---|
| 非常重要 / 值得注意 / 建议记住 | 说明后果或场景 |
| 最容易被追问 / 最容易踩坑 | "面试官通常会追问……" |
| 这个技巧很实用 | 直接给技巧 |
| 强烈建议 / 一定要 | "如果不……，会……" |

## 四、模糊归因

| 看到 | 换成 |
|---|---|
| 业内普遍认为 / 有观点指出 | 给出具体来源，或删掉归因直接陈述 |
| 很多人说 / 大家都觉得 | 同上 |
| 研究表明 | 给出研究名，否则删掉 |

## 五、连接词与过渡

高频且多数可直接删：

此外、同时、另外、值得注意的是、需要指出的是、综上所述、总而言之、首先/其次/最后（机械排序时）、不仅如此、更重要的是。

判断方法：删掉后句子依然通顺、逻辑不变，就删。段落之间的关系靠内容承接，不靠连接词。

## 六、翻译腔句式（中文特有）

| 看到 | 换成 |
|---|---|
| 对 X 进行了 Y / 对 X 做了 Y 的处理 | 直接动词："优化了 X" |
| 基于……的基础上 | "基于……"或"在……基础上"，二选一 |
| 对于这个问题，我们需要考虑的是 | "这个问题要考虑的是" |
| 关于……方面 | "在……上"或直接删 |
| 通过……的方式 | "用……" |
| 使得……得以…… | "因此……"或直接陈述结果 |
| 被认为是一个……的过程 | "这其实是一个……的过程"或直接说过程 |

## 七、名词化与被动堆叠

| 看到 | 换成 |
|---|---|
| 进行了优化 / 实现了提升 / 完成了改造 | 优化了 / 提升了 / 改造了 |
| 问题被得到了解决 | 问题解决了 |
| 由团队进行了评审 | 团队评审过 |

技术文档里被动不是错，连续三句被动才是问题。出现"被……所……"的结构直接改主动。

## 八、三段式与清单癖

AI 默认把观点凑成三组，且三项排列整齐、字数相近。识别方法：三项里去掉一项，意思是否明显变弱？不弱就是凑数。

改写：保留真正重要的那项，或者把三项拆成有先后的步骤。并列关系确实存在时才用列表。

## 九、标点与节奏

- **破折号**：一段里超过两个就审视；多数可以换成逗号或句号
- **冒号+列表**：连续三段都用"分为以下几点"会显得机械
- **句子长度**：AI 的句子长度分布很窄。真实写作里有短句（四五个字）和长句交替
- **段落长度**：每段三到五行是 AI 的舒适区；人写东西会突然来一段一行的

## 十、英文维基列出的模式（可作为补充扫描）

夸大的象征意义、宣传性语言、以 -ing 结尾的肤浅分析（"highlighting the importance of…"）、模糊归因、破折号过度、三段式法则、AI 词汇（delve、crucial、pivotal、landscape、tapestry）、否定式排比（"not only… but also…"）、过多的连接性短语。

中文写作里对应的就是上面第一到第七节的内容。

## 扫描顺序

1. 段落开头：有没有元话语和结构宣告
2. 句子中段：有没有对仗模板、名词化、翻译腔
3. 段尾：有没有评价性包装和总结癖
4. 全文：连接词密度、破折号数量、句子长度分布

扫描只负责找候选，删不删仍然用 SKILL.md 的判断标准。
